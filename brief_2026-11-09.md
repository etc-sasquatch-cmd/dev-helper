## Decisions made that are not in the SPEC
- Breaks auto-start after a focus block (switch in the UI, on by default). Focus never
  auto-starts, because it needs a skill tag.
- No auto-start if the end was noticed more than 120 seconds late (restart or PC sleep).
- A skipped focus block does not count as a completed Pomodoro and does not ask for a recap.
  Its partial running time is stored.
- Reset during a phase returns to the start of that phase. Reset while idle restarts the cycle.
- Skill and work type are both required to start a focus block. Skill is a plain name list
  until M4 adds targets and roadmap links.
- Changing the preset affects the next phase, never the one in progress.
- The last remaining preset cannot be deleted.
- Timer position lives in `settings` keys `timer.next_phase`, `timer.completed_focus`,
  `timer.preset_id`. UI preferences use `ui.*` keys.

## Findings to carry into later milestones

**M2 (YouTube)**
- The Lofi Girl live stream `jfKfPfyJRdk` returned player error **151** in the native window.
  Meaning unknown; it is per-video, since another video played from the same window. Look it
  up before building, show a clear message for videos that cannot be embedded, and test the
  user's real playlists early.
- What made playback work: page served from `http://127.0.0.1:<port>`, a
  `<meta name="referrer" content="strict-origin-when-cross-origin">` tag, and
  `origin: window.location.origin` in `playerVars`. See `spikes/spike_youtube.py` and
  `spikes/youtube_player.js`.
- JS to Python events use NiceGUI's `emitEvent(name, data)` with `ui.on(name, handler)`.
- The window is currently 340x560. The player must stay at least 200x200 and uncovered,
  including in compact mode (300x250), so the compact layout needs rethinking for M2.

**M5 (capture)**
- Hook input can start with a byte-order mark. Read stdin as bytes and decode with
  `utf-8-sig` (see `spikes/spike_hook.py`).
- Hook payload keys seen for `UserPromptSubmit`: `cwd`, `hook_event_name`, `permission_mode`,
  `prompt`, `prompt_id`, `scratchpad_dir`, `session_id`, `transcript_path`.
- The transcript had 16 record types, not just `user` and `assistant`, and the session ID
  appears as both `sessionId` and `session_id`. Token usage sits in `message.usage`.
- The assistant was blocked by the auto-mode safety check from writing
  `.claude/settings.local.json` with a hook in it. The user had to create that file by hand.
  Expect the same for the M5 installer test; the in-app installer itself is unaffected.

**M6 (day view)**
- `pomodoro_block` stores start, end, and total running seconds, but not when each pause
  happened. Splitting a paused block at a quarter boundary would be approximate. Add a small
  pause-interval table at the start of M6.

**M7 (agents)**
- Working call: `claude -p --output-format json --json-schema <schema> --tools "" --model haiku
  --no-session-persistence`, prompt on stdin, `FOCUSDECK_AGENT=1`, run in an empty temp folder.
- The validated answer is in the `structured_output` key of the JSON envelope. `usage`,
  `total_cost_usd`, and `modelUsage` are there too.

## Working agreements learned today
- **Git:** the user runs every commit and push. End each milestone with the exact commands.
  Read-only git (`status`, `log`, `fetch`) is fine to run. Never force-push.
- **Git identity:** this repo has a personal commit email set in its local git config
  (not the global one). Author name stays `estebant2sasquatch`. GitHub account is
  `etc-sasquatch-cmd`.
- **Real runs** by the assistant use a scratch database plus screenshots of only the
  FocusDeck window. Clicks, sound, and notifications always need the user.
